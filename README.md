# Сервис приёма и управления заявками на ремонт и обслуживание

Веб-приложение на базе **Flask** и **SQLite** для мгновенной регистрации технических заявок через QR-коды в помещениях, автоматической оценки их критичности с помощью локального ИИ и удобного управления статусами для администраторов.

---

## Ключевые возможности

* **Мгновенный доступ по QR-коду:** Уникальные QR-коды для каждого кабинета автоматически подставляют локацию в форму заявки.
* **Автономный ИИ-приоритизатор (`ai_helper.py`):** Локальный классификатор анализирует текст проблемы и автоматически назначает уровень приоритета (критический, высокий, средний, низкий) без обращения к внешним API.
* **Защита от дубликатов:** Бэкенд проверяет наличие активных похожих заявок в том же кабинете перед созданием новой, предотвращая спам.
* **Панель администратора:** Единый интерфейс для отслеживания заявок, фильтрации по приоритетам и смены статусов выполнения.
* **Журналирование действий (`logger.py`):** Полное логирование ключевых событий и изменений статусов в системе.

## 🗄️ Схема базы данных (`database.db`)

Проект использует реляционную БД **SQLite** с тремя основными таблицами:

```text
+-----------------------+       +-----------------------------------+       +-----------------------+

|        users          |       |             tickets               |       |         rooms         |
+-----------------------+       +-----------------------------------+       +-----------------------+

| id (PK, INTEGER)      |<--+   | id (PK, INTEGER)                  |   +-->| id (PK, INTEGER)      |
| username (TEXT)       |   |   | title (TEXT)                      |   |   | number (TEXT)         |
| password_hash (TEXT)  |   |   | description (TEXT)                |   |   | floor (INTEGER)       |
| role (TEXT)           |   |   | priority (TEXT) - назначено ИИ    |   |   | description (TEXT)    |
+-----------------------+   |   | status (TEXT)                     |   |   +-----------------------+

                            |   | created_at (DATETIME)             |   |
                            +---| assigned_to (FK -> users.id)      |   |

                                | room_id (FK -> rooms.id)          |---+
                                +-----------------------------------+
```

## Установка и запуск

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   cd projectQQ
   ```

2. **Установите зависимости:**
   ```bash
   pip install flask
   ```

3. **Запустите сервер:**
   ```bash
   python app.py
   ```

4. **Публичный доступ (через туннелирование):**
   Для демонстрации с мобильных устройств вне локальной сети запустите туннель на порт приложения (по умолчанию `5000`):
   ```bash
   ngrok http 5000
   ```
